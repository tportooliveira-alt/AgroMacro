# AgroMacro — Design System "Brutalismo Premium"

## 1. PALETA DE CORES

### Cores Primárias
- **Preto Titânio**: #0F1318 (fundo principal)
- **Terra Roxa**: #8B4513 (alertas, CTAs, dados críticos)
- **Branco Osso**: #FFFEF0 (tipografia, max contrast)

### Cinzas Industriais
- Dark: #1A1A1A
- Mid-Dark: #2A2A2A
- Mid: #3D3D3D
- Light: #4A4A4A
- Border: #5A5A5A

### Acentos
- Verde Titânio: #00796B
- Vermelho Alerta: #DC2626
- Âmbar Cautela: #B45309

## 2. TIPOGRAFIA

### Headlines
- **Fonte**: Inter Bold / JetBrains Mono Bold
- **Tamanhos**: 32px (H1), 24px (H2), 20px (H3), 16px (H4)
- **Cor**: Branco Osso (#FFFEF0)
- **Letter Spacing**: -0.5px

### Body Text
- **Fonte**: Inter Regular / JetBrains Mono (números)
- **Tamanhos**: 14px (normal), 12px (small)
- **Cor**: Branco Osso
- **Line Height**: 1.5

### Numbers (KPIs)
- **Fonte**: DM Mono Bold ou JetBrains Mono
- **Tamanho**: 28px-42px
- **Cor**: Terra Roxa ou Verde Titânio
- **Kerning**: Tight

## 3. COMPONENTES

### Card Padrão
- Fundo: #1A1A1A
- Borda: 1px #3D3D3D
- Border Radius: 8px
- Padding: 16px
- Gap interno: 12px

### Button Padrão
- Fundo: Terra Roxa (#8B4513)
- Text: Branco Osso
- Padding: 12px 24px
- Border Radius: 6px
- Font Weight: 600

### Input/Form
- Fundo: #2A2A2A
- Border: 1px #4A4A4A (focus: Terra Roxa)
- Padding: 12px 16px
- Border Radius: 6px
- Text: Branco Osso

## 4. LAYOUT GRID

- Mobile: 4 colunas, gap 12px
- Tablet: 8 colunas, gap 16px
- Desktop: 12 colunas, gap 16px

## 5. LOGO/ÍCONE

### Conceito: Topografia Nelore
- Linhas de contorno (estilo mapa de elevação)
- Cupim + Dorso em curvas minimalistas
- SVG Stroke-based
- Versões: 192px, 512px, favicon
