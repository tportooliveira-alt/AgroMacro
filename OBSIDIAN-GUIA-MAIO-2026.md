## 📌 O QUE É OBSIDIAN?

Aplicativo de gerenciamento de conhecimento pessoal (PKM):
- **Armazena** notas em Markdown simples (`.md`)
- **Conecta** ideias com links bidirecionais
- **Visualiza** com Graph View
- **Acessa offline** - dados sempre locais
- **Grátis** para uso pessoal

---

## ⚡ VANTAGENS PRINCIPAIS

✅ **Privacidade Total** - Dados locais, nenhuma conta necessária  
✅ **Performance Rápida** - Busca instantânea, sem lag  
✅ **Pensamento Conectado** - Links bidirecionais criam rede de conhecimento  
✅ **Flexibilidade** - Customize infinitamente com plugins  
✅ **Gratuito** - 100% grátis para uso pessoal  
✅ **Extensível** - Plugin API com comunidade ativa  

---

## ❌ DESVANTAGENS

❌ **Curva de Aprendizado Alta** - 3-6 meses pra ver valor real  
❌ **Sem Colaboração** - Puramente pessoal, não funciona em equipes  
❌ **Sync Pago** - Sincronizar entre dispositivos custa $8-10/mês  
❌ **Sem Web Version** - Precisa baixar em cada dispositivo  
❌ **Requer Disciplina** - Você organiza, sem estrutura automática  

---

## 🎯 RECURSOS PRINCIPAIS

### 🔗 Linking (Conexão de Notas)
```markdown
[[Nome da Nota]]  → cria link bidirecional automático
```

### 📊 Graph View
- Visualiza todas as notas como nós
- Mostra conexões entre notas
- Ajuda a descobrir padrões

### 🎨 Canvas
- Espaço infinito 2D para arranjar notas
- Ideal para: mind maps, fluxogramas

### 🏷️ Tagging
```markdown
#tag-minuscula  (1-2 palavras, singular)
```

### 📋 Core Plugins (Grátis)
- **Dataview** → Bancos de dados consultáveis
- **Calendar** → Visualizar por data
- **Kanban** → Quadros (To Do → Doing → Done)
- **Templater** → Modelos automáticos
- **Excalidraw** → Diagramas visuais
- **Backlinks** → Ver quem linkei pra mim

### 📝 Obsidian Bases (Novo!)
- Visualizações: tabela, card, lista, mapa
- Filtros, fórmulas, resumos

## 💡 WORKFLOWS RECOMENDADOS

### Workflow 1: Pesquisador
1. Capture em Daily Notes
2. Semanal: extraia insights
3. Crie notas "Conceito" linkadas
4. Revise com Dataview

### Workflow 2: Projetos (Seu Caso!)
1. Pasta por projeto (PARA)
2. Kanban para tarefas
3. Notas de "Decisões" + "Aprendizados"
4. Templater para consistência
5. Review mensal

### Workflow 3: PKM Puro
1. Daily Note → ideias rápidas
2. Semanal → extrair notas de conceito
3. MOC (Map of Content) para tópicos
4. Graph view para navegar
5. Refinar conexões

## 🎯 MELHORES PRÁTICAS

### Tagging
```
✅ #tag-simples (1-2 palavras)
✅ #tipo-especifico
❌ #muito-longo-e-especifico
❌ #a/b/c/d/e (muitos níveis)
```

### Estrutura de Nota
```markdown
---
aliases: [Alt1, Alt2]
tags: [tag1, tag2]
created: 2026-05-14
---

# Título da Nota

Conteúdo...

## Links Relacionados
[[Nota A]]
[[Nota B]]
```

### Revisão Periódica
- **Daily**: Capture rápido
- **Semanal**: Extraia principais insights
- **Mensal**: Conecte ideias
- **Trimestral**: Veja padrões
