## 🟡 O QUE FALTA (Critical Path)

### ❌ Firebase Credentials Management
- **Issue**: API keys em plaintext em firebase-sync.js
- **LGPD Violation**: Chaves IA (Gemini, Groq, Cerebras) também em plaintext em ia-consultor.js
- **Solução**: Create `.env.local` (gitignored) + load via init script
- **Priority**: 🔴 CRITICAL (antes de qualquer deploy)
- **Effort**: 2 horas

### ⚠️ Conflict Resolution Refinement
- **Current**: Last-write-wins (timestamp compare)
- **Issue**: Doesn't handle simultaneous writes or partial sync states
- **Needed**: 
  - Device ID tracking (`agromacro_device_id` exists ✓)
  - Priority tiebreaker: newer device ID > older
  - Audit trail: log every merge resolution
- **Effort**: 4 horas

### ⚠️ Offline Mode Edge Cases
- **Scenario 1**: Edit while offline → sync fails → retry logic?
- **Scenario 2**: Delete event locally, then reconnect → Firestore still has it?
- **Scenario 3**: Two devices both offline, edit same lote, both reconnect
- **Solution**: Implement undo/estorno tracking + reconciliation log
- **Effort**: 6 horas (complex state machine)

### ⚠️ Batch Size Limit
- **Current**: `syncLocalToFirestore()` uploads ALL events in one batch
- **Issue**: Firestore batch limit = 500 docs; hits error on 746+ events
- **Needed**: Chunk events into 50-doc batches, retry on failure
- **Effort**: 3 horas

### ⚠️ Event Schema Migration
- **Issue**: Existing 746 events in localStorage don't have `fazendaId` field
- **Needed**: Add `fazendaId` to each event during first sync
- **Risk**: If wrong fazenda assigned → data cross-contamination
- **Solution**: Prompt user to confirm fazenda before first sync
- **Effort**: 2 horas

### ❌ Multi-Device Sync Testing
- **Not Done**: Test 2+ devices editing same data simultaneously
- **Needed**: 
  - Create test scenario (2 browser tabs or 2 physical devices)
  - Verify no data loss
  - Verify conflict resolution applied correctly
- **Effort**: 3 horas (manual testing)

### ❌ Admin Dashboard for Multi-Tenant
- **Not Done**: UI for farm owner to manage members, permissions
- **Needed**:
  - Add member page (invite by email)
  - Change member role (dono/admin/peao)

  - View farm audit log

## 🚨 Known Risks

1. **LGPD Compliance**: API keys in code = violation (affects compliance deadline)
2. **Cross-Fazenda Contamination**: If fazendaId migration wrong, data polluted
3. **Batch Upload Failure**: 746 events don't fit in single Firestore batch (500 doc limit)
4. **No Undo on Delete**: If user deletes event locally then goes offline, Firestore still has it
5. **Firebase Quota**: Each batch.set() counts as 1 write; 746 events = 746 writes (risk exceeding daily quota on large farm)
